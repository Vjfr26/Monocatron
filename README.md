# Monocatron

Plataformas arcade para el navegador, hecho con Phaser 3: atrapa las estrellas, esquiva las bombas y derrota al jefe de cada mundo.

## Jugar

```bash
python3 -m http.server 8000
```

Abre <http://localhost:8000>.

Flechas o A/D para moverte, ↑, W o Espacio para saltar, P para pausar y M para el sonido. En el móvil hay controles táctiles.
